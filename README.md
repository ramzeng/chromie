# Chromie

一个面向 macOS 的本地资产管理工具。当前支持多个本地账户、资产账户以及 CN、HK、US、CC 市场持仓的本地维护。

## 当前能力

- 创建、切换、改名和删除本地账户
- 在账户下管理多个资产账户
- 在资产视图中按资产账户或持仓分组查看币种与锚定市值
- 维护持仓的市场、代码、名称、币种、数量和当前价格
- 创建持仓分组，并混合加入任意资产账户中的持仓；每项持仓最多归属一个分组
- 自动获取汇率，将不同币种换算为账户锚定币种并统一计算持仓占比
- 手动维护支付宝资产账户及其持仓
- 手动维护中银国际、招商银行、中国银行和通用资产账户及其持仓
- 通过本机 Futu OpenD 自动同步富途牛牛港美股持仓和分币种现金
- 通过 OKX 只读 API 自动同步交易账户和资金账户资产
- 单独导出和导入账户
- 手动创建资产快照，在最新版与只读历史版本之间切换

## 资产快照

账户侧栏中的“时间机器”会打开版本表格，用于创建快照并切换最新版和历史版本。快照会保存当前账户结构、持仓价格以及当时可用的汇率；查看历史版本时，编辑和自动同步会暂停，返回最新版后恢复正常。

快照仅保存在本机，可单独删除，也会随账户备份一起导出和导入。旧版本地数据及旧版账户备份仍可直接读取。

## 富途牛牛同步

先启动 Futu OpenD 并开启 WebSocket 服务。资产账户选择富途牛牛并开启自动同步后，可填写 Futu OpenD 地址、端口、密钥和同步间隔。默认连接 `127.0.0.1:33333`，开启后会立即同步，随后默认每 30 秒刷新一次。

SSL 和备用密钥可在启动 Chromie 时设置：

- `FUTU_OPEND_WS_SSL`
- `FUTU_OPEND_WS_KEY`

同步为只读操作，不会解锁交易或提交订单。

## OKX 同步

在 OKX 创建仅有读取权限的 API Key。资产账户选择欧易并开启自动同步后，填写 API Key、Secret Key、Passphrase 和同步间隔。开启后会立即同步，随后默认每 30 秒刷新一次。

API 配置仅保存在本地。同步会合并交易账户和资金账户余额，不会提交订单或划转资产。

## 汇率与锚定市值

每个账户可以从 `CNY`、`HKD` 和 `USD` 中选择独立的锚定币种，默认使用 `CNY`。持仓市值继续保留原币种，锚定市值通过 Coinbase 公共汇率接口自动换算，全部持仓占比按锚定市值统一计算。

应用启动后会获取最新汇率，并每 15 分钟自动刷新。最近一次成功汇率缓存在本机；网络请求失败时继续使用缓存。若某个已定价持仓缺少汇率，则暂不显示整个列表的占比，避免产生不完整的百分比。

## 数据迁移

在账户菜单中选择“导出账户”，可将当前账户生成为一个 JSON 备份文件。新设备首次打开时可直接选择“导入账户”，也可以从账户菜单导入。导入会先校验文件，再新增一个账户，不会覆盖现有账户。

备份包含账户、资产账户、持有人、持仓分组、持仓、同步配置及 API 凭据，请妥善保管。

## 技术栈

- Electron + electron-vite
- React + TypeScript
- Tailwind CSS v4
- shadcn/ui
- pnpm

## 开发

```bash
pnpm install
pnpm dev
```

## 检查与构建

```bash
pnpm typecheck
pnpm build
pnpm build:mac
```

`pnpm build:mac` 会在 `dist/` 下生成 macOS 安装包。正式分发前还需要配置应用图标、Apple Developer 签名与 notarization。

## 目录

```text
src/
├── main/       # Electron 主进程
├── preload/    # 安全的渲染层桥接
└── renderer/   # React 应用与 shadcn/ui 组件
```
